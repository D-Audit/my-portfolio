## 🚀 Getting Started

### Prerequisites
- Node.js 14+ with Corepack
- Yarn package manager

### Installation

```bash
cd my-portfolio
corepack yarn install
```

### Development

```bash
corepack yarn develop
```

The site will be available at `http://localhost:8000`

### Build for Production

```bash
corepack yarn build
```
